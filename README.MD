# gitClasses

This repository contains a small HTML learning project focused on basic web development concepts.

## Project purpose

The project demonstrates common HTML elements and styling techniques, including:

- headings and paragraphs
- links and images
- lists (ordered and unordered)
- tables
- forms
- inline text formatting such as bold, italic, underline, and highlight

## Included files

- `gulshan.html` — main HTML page showcasing the examples
- `gulshan/` — supporting folder with sample assets/data files

## How to view the project

1. Open `gulshan.html` in a browser.
2. You can also use a local development server if you prefer.

## Notes

This repository is intended for learning and practice, especially for beginners exploring HTML structure and basic page layout.
